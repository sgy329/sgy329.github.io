대표 프로젝트

C# / WinForms / WPF

무전기 생산 시험 자동화

작업자가 계측기를 직접 설정하던 공정을 C# 시험 프로그램으로 자동화했습니다. UART·USB로 무전기를, GPIB·LAN으로 계측기를 제어해 음성 품질, 채널 스캔, 비상 호출 시험을 실행했습니다.

현장 적용 시험 조건 설정부터 판정과 결과 저장까지 한 프로그램으로 처리했습니다. 작업자 피드백을 반영해 시험 화면을 수정하고 현지 생산 라인에서 프로그램 사용을 교육했습니다.

STM32C071 / USB HID / EP0

간헐 USB HID 인식 실패 개선

특정 무전기 호스트에서 키패드 마이크 인식이 간헐적으로 실패하는 현상을 실제 장비로 재현했습니다. SET_ADDRESS 요청과 EP0 STATUS IN 처리 경로를 추적해 USB 스택의 초기화 로직을 수정했습니다.

검증 동일 호스트에 반복 연결해 수정 전후의 인식 성공 여부를 비교하고 실패 빈도가 낮아진 것을 확인했습니다.

RTL-SDR / Python / I/Q

4FSK 변조 품질 분석

RTL-SDR로 수집한 I/Q 데이터에서 반송파 오프셋을 보정하고 심볼 판정 시점을 찾아, 주파수 편이와 FSK Error를 계산하는 Python 스크립트를 작성했습니다.

검증 Aeroflex 3920과 비교해 측정 차이를 확인했습니다. 생산 검사 적용을 위해서는 동일 조건에서 계측기와의 일치도를 추가 검증해야 합니다.

캡처 예시의 4점 환산 편이 ±940.81 Hz · FSK Error 중앙값 1.948%

경력 및 보유 기술

무선 인증 시험에서 쌓은 계측·문서화 경험을 생산 시험 SW와 펌웨어 검증에 활용해 왔습니다.
